## [1.0.0] - 2026-07-08

### Added
- Initial release: webhook-only Discord alerts (joins, quits, first joins, deaths, watched commands, TPS, watchdog, server start/stop), per-alert channel routing, rate limiting, digest mode, join-burst and new-country anomaly detection, optional JDA bot mode with /online /tps /whereis, public ScappiWatchAPI.
